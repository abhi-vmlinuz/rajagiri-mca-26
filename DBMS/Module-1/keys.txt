Primary Key
Definition: A unique identifier for a table. It uniquely identifies each record in a database table.
- Only 1 primary key for a table


Candidate Key (Minimal Superkey, unqiuely identifying a row using minimal super key attributes)
Definition: A set of one or more columns that can uniquely identify a row in a table. A table can have multiple candidate keys, and one of them is chosen as the Primary Key.
- No Nulls values


Super Key
Definition: Any combination of columns that can uniquely identify a row in a table. A super key is a superset of a candidate key.
