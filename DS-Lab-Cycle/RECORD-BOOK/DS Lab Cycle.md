**Project \[Model Question\]**  
Develop a **menu-driven C program** to implement **any one** of the following data structures:

* Singly Linked List  
* Circular Linked List  
* Doubly Linked List  
* Lined Queue  
* Linked Stack  
* Binary Search Tree

The selected data structure should be used to store the following student information:

* Roll Number  
* Name  
* Marks of Five Subjects

**Functional Requirements**

The program should provide the following functionalities:

1. **Add Student Record**  
   * Accept and store student details in the selected data structure.  
2. **Display Student Records**  
   * Display all student records currently stored in the data structure.  
3. **Store/Save Records in an External File**  
   * Save all student records to a file.  
4. **Read/Open Records from the File**  
   * Retrieve student records from the file.  
5. **Update the records by searching with roll no**  
   * Name and marks should be updated  
6. **Delete Records by Searching with roll no**  
   * Search and delete  
7. Sort the records in the data structure  
   * By roll no  
   * By student name  
8. **Exit**  
   * Terminate the program gracefully.
